## Personal Site of Anna Garcia

Built with React 18 + Vite. Hosted on DreamHost at [annagarcia.live](https://www.annagarcia.live).

## Local Development

Requires Node 18+.

```bash
npm install
npm start
```

Opens at [http://localhost:5173](http://localhost:5173).

## Deploy to DreamHost

1. Build the production files:

```bash
npm run build
```

2. Upload the contents of `dist/`
